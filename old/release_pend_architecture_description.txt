RULE found in CSV? (No → SKIP)
seq_ordr=Y + cert_no repeats? (Yes → SKIP SEQ ORDER)
aply_tod_updt=Y? (Yes → run TOD update, fail → SKIP)

Draft loop (purple dashed back-arrow):

Condition note + AFV (if flags set)
CLAIM_TYPE split:

HCFA → CPS450.01: ineligibility codes, hcfa_data_entry
Result — DONE or error status appended per claim; green loop-back arrow shows the next-claim iteration
