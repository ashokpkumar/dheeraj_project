MAIN sheet · Sheet1 & DxCodesRef · CPS450 / BLX2460 / CPS506 screens

Every input and output in the Pend/Release macro

NewPendRelease_Macro runs claims through HCFA (CPS450) and UB (BLX2460) mainframe release screens. Almost nothing is unconditional — most fields on the MAIN sheet are only read when a matching toggle cell is set to a specific value. This page maps every cell and column to the condition that makes it live, and to what the macro writes back.

Reading the tables: row column S · BN $ QTY is listed as input, only when Q6 Apply BN Code/$ Qty = Y — the pattern the whole reference follows: “BN $ QTY is taken as input only when APPLY BN QTY = Y.”
